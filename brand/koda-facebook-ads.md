# KODA — Facebook Ads creative kit

**Goal:** stop the scroll, hit the nerve (fake screenshots = stolen money), and
make a mobile-money merchant reach for their phone to sign up — free, in seconds.

Built on 2026 Meta creative rules: **4:5 feed** (1080×1350, or 1440×1800 for
retina), **9:16 for Stories/Reels** (1080×1920); keep the **top 14% and bottom
20% clear of text/logo**; one focal point; faces making eye contact; answer
*what is this / who's it for / why now* in ~2 seconds; a clear offer + CTA.

### How to use these 5 image prompts
1. Paste each prompt into your image tool (Midjourney, Flux, Ideogram, GPT-image, etc.).
2. **Generate the image CLEAN (no baked-in text)** — AI still garbles words. Each prompt leaves **negative space** for the headline.
3. Add the **overlay text** (given per image) afterwards in Canva/your editor, inside the safe zones, in the KODA colours.
4. KODA palette for overlays: deep pine green `#081813` / `#0C231C`, gold `#E8A11F`, cream `#E9E4D5`, muted sage `#9BA79B`.
5. Midjourney users: append `--ar 4:5 --style raw --v 6` (use `--ar 9:16` for the Stories cut).

Each image targets a different step of buying psychology: **Problem → Mechanism → Transformation → Proof → Brand hook.** Run all five, let Meta find the winner, then scale it.

## THE AD — one reusable prompt to generate the Facebook ad copy

Feed this to any AI (or use it as your own brief). It encodes KODA's real,
honest positioning so the copy never overclaims.

> **Copy-generation prompt:**
>
> You are a direct-response copywriter writing a Facebook ad for **KODA**, a
> mobile-money **payment-verification** service for African merchants and
> developers. Write ad copy that makes a merchant stop scrolling and sign up now.
>
> **Product truth (do not contradict):** Merchants lose real money because
> customers "pay" with screenshots that are edited or faked in seconds. KODA
> verifies any mobile-money payment against the **operator's own confirmation SMS**
> (Orange Money, M-Pesa, Airtel, MTN MoMo, Wave + 200 more) and returns a
> fraud-checked **verdict in about 3 seconds** — no telco API, nothing for the
> customer to install. It is **free to start** (10 verifications/month, no card).
> The only requirement: the merchant receives the operator's confirmation SMS on
> their own merchant mobile-money number.
>
> **Honesty guardrails — never claim:** that KODA is a bank, wallet, processor or
> escrow; that it holds or moves money; that it guarantees against operator-side
> reversals or proves final settlement; "guaranteed", "100% safe", "bank-grade",
> "unhackable". KODA makes you **first to know** a payment is real — say exactly that.
>
> **Write:** (1) 3 **primary-text** options, each 2–4 short lines, hook in the
> first line, 1 emoji max, ending in a soft CTA; (2) 5 **headlines** (≤40 chars);
> (3) 3 **descriptions** (≤30 chars); (4) recommended **CTA button**
> (e.g. "Sign Up" / "Learn More"). Tone: urgent, plain, merchant-to-merchant,
> no jargon. Give an **English set and a French (DRC) set**.

## Launch notes
- **Pair each image with a different primary text** and let Meta's algorithm find the winner (Advantage+ / dynamic creative). Don't guess — test.
- **Audience:** merchants/retail, mobile-money users, small-business owners; start DRC + your live-rail countries, then widen.
- **Primary CTA destination:** `https://kodajnn.com/get-started`. The first-visit welcome modal on the site reinforces the same hook ("Stop losing money to fake screenshots").
- **Offer honesty:** only promise "free to start / 10 verifications free, no card" — which is true. Don't add a fake deadline; a real one ("free credit for signups this week") only if you'll honour it.
- **French-first for DRC audiences**, English for pan-African/developer reach.
